Task Management Backend API

Features:
- User Authentication
- JWT Authentication
- Role-based Access
- Project Management
- Task Management
- Dashboard API

Technologies Used:
- Node.js
- Express.js
- MongoDB
- JWT
- bcryptjs

API Endpoints:
POST /api/auth/register
POST /api/auth/login
GET /api/protected
POST /api/projects
POST /api/tasks
PUT /api/tasks/:id
GET /api/dashboard

How to Run:
1. npm install
2. node server.js

Server runs on:
http://localhost:5000
